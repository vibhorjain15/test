This is a custom/dynamic grid. You can define formulas for cells within a row. When the responder adds rows, the formulas will be applied in the new rows. Additionally, you have the option to set an aggregate row and provide a formula in that row for a consolidated view of the results. Example: You can sum all of the cells in column A by inputting SUM(A1:A1), and when a user adds a row it will automatically include the new row in the formula ex. SUM(A1:A2).
