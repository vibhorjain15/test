How to use Grid validations and Formula?

Frequently asked questions

  1. These formulas will work with both standard grid/table and customized grid.
  2. Utilize dynamic formulas within custom grids at the template level that adjust according to the number of added rows. This functionality allows you to establish formulas for individual cells, while our algorithm automatically generates corresponding formulas for subsequent rows. For example, if you utilize the formula =SUM(A1:B1) in a specific cell, this formula dynamically extends to any new rows added by the user. For instance, if the user adds a second row, the formula will automatically apply to the new rows as =SUM(A2:B2). To maintain fixed row references, use the '$' symbol, as in A$1. This ensures that the formula remains static and does not dynamically adjust to new rows added.
  3. Opt for the aggregation row functionality to execute dynamic aggregation operations within the final row of a customized grid, facilitating formulas like =SUM(A1:A4) that dynamically update with the addition or removal of rows. For example if this formula =SUM(A1:A1) is configured in the Aggregate row then the formula would not be limited to cell A1:A1 but will dynamically apply across the entire range i.e. A1:A(n).
  4. You will not be able to type in the cell wherein you have added any validations. This cell will be greyed out.
  5. You can copy the formula entered in the grid by clicking on the “copy” button and make any required changes to the table. Limited edits are allowed if the template has associated responses.
  6. If the column type is numeric or percentage and the formula entered gives a text value then the grid will show you a #VALUE! error. Please make sure the column type is text in this case.
    Example: In cell G1 we want to look up for wherever the start year entered by the user is 2015 and return the last name entered in corresponding 3rd column C1. Cell G1 is a numeric value type column and since the returning value is not a numeric field it is showing #Value! As the error.

List of Errors

A handful of errors can appear in a cell when a formula is applied and cannot be resolved. Please find the list of most common errors below:

Error Meaning
#DIV/0! Trying to divide by 0
#N/A! A formula or a function inside a formula cannot find the referencevalue
#NAME? Text in the formula is not recognized
#NULL! A space was used in formulas that reference multiple ranges; a comma separates range references
#NUM! A formula has invalid numeric data for the type of operation
#REF! A reference is invalid
#VALUE! The wrong type of operand or function argument is used
#CYCLE! It occurs when a formula refers to its own cell, both directly and indirectly.
#ERROR! It indicates that there is an unknown error in a formula.

The SUM function allows you to add values. You can add individual values, cell references or ranges or a mix of all three.
Here’s an example. Let's say you want to find the total of AUM added by the user in column A1 to A4 in the table below in cell A5. The SUMIF function allows you to sum the values in a range that meet criteria that you specify.
For example, suppose that in a column that contains numbers, you want to sum only the values that are larger than 10. You can use the following formula: =SUMIF(C1:C10,">10")

3. SUMPRODUCT

The SUMPRODUCT function returns the sum of the products of corresponding ranges or arrays. The default operation is multiplication, but addition, subtraction, and division are also possible.
In this example, we'll use SUMPRODUCT to return the Overall weighted score in cell D7. The formula we have used is =SUMPRODUCT(B1:B6,C1:C6)/SUM(C1:C6)

Each cell in column B is multiplied by its corresponding cell in the same row in column C, and the results are added up. Now to find the weighted average we will divide the first part SUMPRODUCT(B1:B6,C1:C6) by the SUM of the weights i.e (SUM(C1:C6))

4. ISBLANK

The ISBLANK function is used to return TRUE when a cell is empty, and FALSE when a cell is not empty. This function can be used if you want to make a column or row mandatory.
Example: Let's say you wanted to make sure that the user did enter the Date in Column B. We can use the below formula and make sure the users do add a value otherwise it will show them an error message.
You can use the following formula:
=IF(ISBLANK(B1), "ERROR.TYPE('Date is required')","")

6. SUBTRACT NUMBERS

To do simple subtraction, use the - (minus sign) arithmetic operator.
Let's say you want to find out the Net flow. In cell A2 we have YTD Inflow and in cell A1 we have YTD outflow. The Net flow will be A2-A1.

8. HLOOKUP

The HLOOKUP searches for a value in the top row of a table or an array of values, and then returns a value in the same column from a row you specify in the table or array. Use this function when your comparison values are located in a row across the top of a table of data, and you want to look down a specified number of rows.
Use VLOOKUP when your comparison values are located in a column to the left of the data you want to find.
Example: In the table below we want to find wherever the Inception date is mentioned as 2001 and return the value entered in corresponding row 4. So the formula would be =HLOOKUP(2001,A1:D4,4,0).

Please note: True and False will not work in the current version of the formula on the platform. Please use 1/TRUE, or 0/FALSE instead.
