Super Admin

Super Admin role has the highest level of access to a firm including firm settings. This type of user can create, delete, and modify entities. This means that Super Admins can control site-wide settings such as adding new users and teams, firm settings, design and export preferences, tag creation, workflows, rating definitions, etc.

We recommend that you share management of your account with other people you trust by granting them administrator privileges.

  • Firm Settings- Yes full access
  • Entity Management- Yes full access
  • Diligence Management- Yes full access
  • Research Management- Yes full access
  • Doc Management- Yes full access
  • Report Management- Yes full access

Business Admin

Business Admin will have access to configure and manage everything in the firm settings apart from security and users/teams. They should be able to view all users/teams but should not be able to edit them. This user can manage tags and custom fields, add workflows, set preferences, email templates etc.

The business admin will have firm wide access to all the other modules available.

  • Firm Settings- Limited Access
  • Entity Management- Yes full access
  • Diligence Management- Yes full access
  • Research Management- Yes full access
  • Doc Management- Yes full access
  • Report Management- Yes full access

Security Admin

Security Admin role will have limited access to the firm settings. They can only configure and manage the firm security settings(domain, IP whitelisting, SAML/SSO and password settings) and users/teams on the platform. They will also receive any notifications regarding user profile activation/locked-out notifications/ access level upgraded/downgraded and when SSO will be enabled/disabled.

  • Firm Settings- Limited Access
  • Entity Management- No access
  • Diligence Management- No access
  • Research Management- No access
  • Doc Management- No access
  • Report Management- No access

Owner

This user has firm-wide read-write access. They can access all entities, create/modify and delete them. Like an Admin, they have all other permissions except access to firm settings.

  • Firm Settings- No access
  • Entity Management- Yes full access
  • Diligence Management- Yes full access
  • Research Management- Yes full access
  • Doc Management- Yes full access
  • Report Management- Yes full access

Contributor Premium

This user doesn’t have access to firm settings and cannot create any new resources, but have access to view/modify/delete all the existing resources. Few other restrictions/capabilities are listed below:

  • Can't activate the template
  • Can't manage project subscribers
  • Can add to-dos/meetings/notes/responses/attachments/AUM data/follow-ups
  • Firm Settings- No access
  • Entity Management- Access and edit existing entities but cannot create new product/vehicle/{{vm.isInvestor? 'manager': 'investor'}}/contact
  • Diligence Management- Cannot modify existing template/project but cannot create new projects, Cannot add or activate a template, Cannot share Diligence with {{vm.isInvestor? 'manager': 'investor'}}
  • Research Management- Can add to-dos/tasks/internal notes and comments for the {{vm.isInvestor? 'manager': 'investor'}}, Cannot trigger workflow or add new subscribers to a questionnaire
  • Doc Management- Yes full access
  • Report Management- Yes full access

Viewer

This type of user can only view all the entities but cannot make any changes to them.This user can also preview and document files but cannot make any changes to them. They do not have access to firm settings.

  • Firm Settings- No access
  • Entity Management- Can only view entities
  • Diligence Management- Can only view Diligences
  • Research Management- Can only view tasks/notes/to-do items
  • Doc Management- Can only view docs
  • Report Management- Cannot export reports into PDF

Restricted Premium

We also have a special user type: Restricted that doesn't have firm-wide access but when added to the platform can be given specific firm/product/project access. This role is very beneficial if you have consultants who work on a project to project basis.
