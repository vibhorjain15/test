1. Can I convert/change the response type if we have associated responses? You cannot convert all the response types when you have associated responses. But you can make the below changes:
  • Single line response type can be converted to paragraph*
  • Dropdown response type can be converted to multiple checkbox*
  • Email response type can be converted into one line or paragraph*
  • Numeric decimal response type to integer and vice versa is allowed
  • Yes/No response type can be converted to Yes/No with explanation for Yes or No and vice versa is allowed
  • Grids and customize grids/tables response types cannot be converted
* vice versa is not allowed
2. What can I edit if the question has associated responses? You can edit the question text as required. For checkbox/dropdown type questions you can add/remove, modify the options and change ordering. For grid and custom grid you can modify the options, add/remove the columns and rows, change ordering as needed.
3. In what scenarios will I see the latest changes (questions added/ deleted/ modified) of the template in the project without activating the template? In all the below scenarios you will see the latest changes without activating the template:
  • When there are no responses available for the questions.
  • When all the external projects of this template version have an “Invited” status.
  • When all the Internal projects of this template version have a “Started” status.
